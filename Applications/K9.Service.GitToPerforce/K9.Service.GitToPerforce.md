# K9.Service.GitToPerforce

Synchronizes a git repository to a Perforce workspace.


## Config Members
| Member                          | Description                                                                         | Default                                              |
|---------------------------------|-------------------------------------------------------------------------------------|------------------------------------------------------|
| `DataRoot`                      | Path to where the Perforce workspace should be created.                             | `D:\GitToPerforce\`                                  |
| `CheckSleep`                    | How often should the change check be made, in seconds.                              | `300`                                                |
| `PerforcePort`                  | The perforce connection string to use to access your server.                        | `ssl:perforce.dotbunny.com:1666`                     |
| `PerforceUsername`              | The perforce username to use when connecting.                                       |                                                      |
| `PerforcePassword`              | The perforce password to use when connecting.                                       |                                                      |
| `PerforceClientName`            | The client name to give the workspace, will be suffixed with the machine name.      | `K9_GitToPerforce_Sync`                              |
| `PerforceWorkspaceStreamName`   | The name of the Stream to use.                                                      | `//NEXUS/Sync`                                       |
| `PerforceCommitMessageTemplate` | The commit message to use when commiting to Perforce.                               | `#K9 Updated Git repository at $GitPath to $GitHash` |
| `PerforceIgnoreFile`            | `We will set the P4IGNORE on the environment were working in.                       | `.p4ignore`                                          |
| `GitRepositoryUrl`              | What should be checked out.                                                         | `https://github.com/dotBunny/NEXUS.git`              |
| `GitBranch`                     | What branch should be checked out.                                                  | `main`                                               |
| `GitRepositoryRelativeRoot`     | Where should the repository be checked out relative to the Perforce workspace root. | `NEXUS`                                              |

## Example GitToPerforceConfig

```json
{
  "PerforceUsername": "my-username",
  "PerforcePassword": "my-password",
  "DataDir": "/app/data"
}
```
