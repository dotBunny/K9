# K9.Service.GitToPerforce

Synchronizes a git repository to a Perforce workspace.

## Perforce Virtual Stream Definition

The plugin itself lives in `/Projects/DETHOL/Plugins/NEXUS` so by creating a virtual stream, and minimizing the view to just the plugin we create a very small footprint setup.
